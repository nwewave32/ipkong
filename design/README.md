# 아이콘 원본

`app_icon_1024.png` — 앱 아이콘의 **마스터**. 저장소에 있는 모든 아이콘이
이 한 장에서 나왔다. 다시 뽑아야 할 일이 생기면 여기서 시작한다.

`pubspec.yaml` 의 `assets` 에 넣지 않았다. 앱에 번들될 이유가 없다.

| | |
|---|---|
| 크기 | 1024×1024 |
| 배경 | `#4C9A5A` — `app.dart` 의 테마 시드(`0xFF4C9A5A`)와 같은 녹색 |
| 글리프 | `#F6F2E7` 크림. 경계 410×640 (전체의 40% × 62.5%) |
| 알파 | **있다** (둥근 모서리가 투명) — 아래 참고 |

## 알파를 그대로 쓰면 안 된다

마스터에는 둥근 모서리가 투명하게 들어 있는데, iOS 아이콘에 그대로 넣으면
두 가지가 터진다.

1. **App Store 가 반려한다.** 1024 마케팅 아이콘에 알파가 있으면 업로드
   검증에서 막힌다.
2. **모서리가 이중으로 깎인다.** iOS 는 어차피 제 수퍼타원 마스크를 씌우는데,
   원본에 이미 둥근 모서리가 있으면 그 위에 또 깎여 가장자리가 지저분해진다.

그래서 **자기 배경색 위에 눌러 담아** 가장자리까지 꽉 찬 불투명 정사각형으로
만든 뒤 각 크기로 줄인다. 투명했던 모서리가 녹색으로 채워지고, 둥글리기는
iOS 가 한다.

## 알림 아이콘만 다르다

`ic_notification.xml` 은 이 PNG 를 줄인 게 아니라 **벡터로 다시 그린 것**이다.
Android 는 알파만 읽어 단색으로 칠하므로 색이 의미 없고, 24dp 에서는 단순화가
필요하다. 마스터에서 글리프를 실측해 24dp 뷰포트로 옮겼고 원본 마스크와 93%
겹친다. 일부러 다른 두 가지:

- 콩 왼쪽 아래의 작은 결각을 뺐다 — 24dp 에서는 얼룩으로만 보인다.
- 잎 아래 곡선을 줄기 **안쪽**에서 닫는다 — 바깥에서 닫으면 닫는 직선이 빈
  공간을 가로질러 얇은 쐐기가 생긴다.

## 다시 만들려면

ImageMagick·Pillow 없이 Swift + CoreGraphics 로 생성했다(맥에 이미 있다).
생성 스크립트는 저장소에 넣지 않았다 — 필요하면 위 설명대로 다시 쓰면 된다.
핵심은 세 가지뿐이다: **불투명하게 눌러 담기**, **적응형 전경은 2/3 로 들이기**,
**스플래시 글리프는 휘도를 알파로**.
